# Coopanion v0.2.14

**Coo 的回复可以用豆包读出来，识别也能走豆包的流式接口；「语音」页多了唤醒词，说一声就开始听**

## 新功能

- **朗读回复**：「语音」页新「朗读」一节，打开后用豆包把回复读成声音。只有用语音问的那一轮会读，打字问的不读；再开口说话、点气泡或打字就停下，同一句第二次直接出声。音效总开关关着时不读，音节叽咕声仍是「音效」里的独立开关。
- **唤醒词**：「语音」页新「唤醒词」一节。写上一行一个的唤醒词、下载唤醒词模型之后，对着麦克风说它就开始听，不必按说话键；灵敏度和两次唤醒的间隔可调。识别在本机的模型上做，录音不上传，关掉唤醒词后不再占 CPU。
- **豆包识别**：识别引擎多了 `doubao`，走火山引擎的流式识别，边说边出字。它和朗读共用一把 Key，在「语音」页填一次。
- **回答更口语**：这一轮的回答会被读出来时，Coo 会被告知少用列表、代码块和括号里的补充。

## 改动

- 设置窗口的「语音输入」页改名「语音」：上半是识别，下半是朗读，最下面是唤醒词。
- 「语音」页的豆包 Key 与转写接口的 Key 分别保存。
- README 写明朗读、唤醒词和豆包识别各自的联网位置。
